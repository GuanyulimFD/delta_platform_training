# Lesson 8.5 Worked Example

## Introduction

This lesson goes through the whole process of querying via the Gateway

## Key Concepts

We are going to go through a simple example of pulling back data from two sources (RDB and HDB), joining some reference data on to the transactional data, and then returning that back to the user

1. The first step is to make some data available in the RDB and HDB. We will use a simple example for both. To add data to the RDB we can run the below while connected to the RDB:

```q
transactionalData:([]sym:();time:();price:())
`transactionalData upsert flip `sym`time`price!
(`AAPL`AAPL`AAPL`TSLA`TSLA`TSLA`MSFT`MSFT`MSFT`GOOG`GOOG`GOOG;2026.11.09D19:00:00.000000000+00:00+(til 12);1.1 9.9 5.5 4.6 15.6 7.8 48.5 21.6 9.4 7.5 1.6 78.1)

referenceData:([]sym:();industry:();region:())
`referenceData upsert flip `sym`industry`region!
(`AAPL`TSLA`MSFT`GOOG;`technology`automotive`computers`websearch;`california`texas`new_york`florida)
```

2. Next we need to add some data to the HDB. We can run the below while connected to the HDB:

```q
dataToSave:flip `sym`time`price!
(`AAPL`AAPL`AAPL`TSLA`TSLA`TSLA`MSFT`MSFT`MSFT`GOOG`GOOG`GOOG;2026.11.08D19:00:00.000000000+00:00+(til 12);4.6 5.8 74.9 5.6 3.4 7.9 8.4 7.6 9.1 23.5 56.4 99.4)
(`$":/opt/kx-training/kxinstall/delta-data/DeltaStreamData/hdblog/2026.11.08/transactionalData/")set .Q.en[`$":/opt/kx-training/kxinstall/delta-data/DeltaStreamData/hdblog";dataToSave]
```

3. Define access functions on both

```q
selectFunc:{[tbl;sd;ed;ids]
  $[`date in cols tbl;
    select from tbl where date within (sd;ed), sym in ids;
    [res: $[.z.D within (sd;ed); select from tbl where sym in ids; 0#value tbl];
     `date xcols update date:.z.D from res]] }
```

4. Define stored procedure on gateway

```q
/ Stored procedure in Gateway
getDataWithAsOf:{[sd;ed;ids]
  / 1. Query transactional data from HDB and RDB, then join
  hTrade: hdbHandle(`selectFunc; `trade; sd; ed; ids);
  rTrade: rdbHandle(`selectFunc; `trade; sd; ed; ids);
  trades: hTrade, rTrade;

  / 2. Query reference/quote data from HDB and RDB, then join
  hQuote: hdbHandle(`selectFunc; `quote; sd; ed; ids);
  rQuote: rdbHandle(`selectFunc; `quote; sd; ed; ids);
  quotes: hQuote, rQuote;

  / 3. Perform as-of join
  / Matches equality on initial columns (sym) and non-equi join on last column (time)
  aj[`sym`time; trades; quotes]
 }
```
