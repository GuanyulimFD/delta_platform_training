# Lesson 6.2 - Messaging Configuration via instance parameter

The first method that will be introduced for configuring messaging is configuring via the Instance Params.

There are 4 parameters that can be configured within the Instance Params for messaging:

| Parameter | Type | Description |
|---|---|---|
| publishChannel | Symbol | Channel name to publish tables on |
| subscriptionChannel | Symbol | Channel name to subscribe to tables on |
| subscriptionTableList | Symbol[] | List of tables to subscribe to. If left empty, the process will subscribe to all tables. |
| realTimeMsgFunct | Analytic | Update function to be used by process |

How this comes together:

1. Process 1 sets **publishChannel** to **channel1** and publishes **tableA**.
2. Process 2 sets **subscriptionChannel** to **channel1** and sets **subscriptionTableList** to **tableA** (or leave empty).
3. Process 2 will now receive data every time process 1 publishes **tableA**. The received table will be processed by the function set in **realTimeMsgFunct** (upd function), which will receive the parameters [tableName;data].
