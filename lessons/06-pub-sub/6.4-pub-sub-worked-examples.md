# Lesson 6.4: Pub-Sub Worked Examples

## Worked Example 1: Subscription and Registration via Messaging APIs

> **Video placeholder in source:** `[Add Video]`

This method demonstrates programmatic control over both sides of the pipeline: the subscriber registers via regsub, the publisher registers as a source via regsrc, data is published, the subscriber unsubscribes, and updates are rechecked to confirm cessation.

1. **Subscriber Registration (sub):**
   ```q
   / Register the subscriber process to receive tableA streams
   .dm.regsub[`; `tableA];
   ```
2. **Publisher / Source Registration (src):**
   ```q
   / Register the publisher/source with a designated source identifier
   .dm.regsrc[`; `tableA; `source1];
   ```
3. **Publishing Data:**
   The publisher pushes data updates using .dm.pub:
   ```q
   / Define dummy table data
   dt: ([] time:.z.T; sym:`AAPL`MSFT; price:150.0 280.5);

   / Publish tableA to matching subscribers
   .dm.pub[`tableA; dt];
   ```
4. **Log Verification:**
   Check the subscriber's update logs. The records for tableA will appear as published.
5. **Unsubscription & Rechecking:**
   Unsubscribe the subscriber process from tableA:
   ```q
   .dm.unsub[`; `tableA];
   ```
   *Recheck:* When the publisher publishes subsequent updates to tableA, check the subscriber logs to confirm no new data rows arrive.

## Worked Example 2: Custom Callbacks

This method demonstrates how to hook custom parsing or logging logic directly to a table name using .dm.addCallback and verifying its execution via .dm.applyCallbacks.

1. **Define a Custom Callback Function:**
   Write a handler function accepting two parameters: [tableName; data].
   ```q
   myCustomHandler: {[t; x]
     0N! "CUSTOM CALLBACK TRIGGERED for table: ", string[t], " | Row count: ", string[count x];
   };
   ```
2. **Register the Callback:**
   Bind your custom function to the target table using .dm.addCallback:
   ```q
   .dm.addCallback[`tableA; `myCustomHandler];
   ```
3. **Verify Execution:**
   Trigger or test the callback integration explicitly:
   ```q
   testData: ([] time:.z.T; sym:`GOOG; price:2700.0);

   / Simulate incoming message evaluation
   .dm.applyCallbacks[`tableA; testData];
   ```
4. **Check Logs:**
   Verify the console output. You will see:
   `CUSTOM CALLBACK TRIGGERED for table: tableA | Row count: 1`
