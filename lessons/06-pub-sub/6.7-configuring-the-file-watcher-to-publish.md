# Lesson 6.7 - Configuring the File Watcher to Publish

_Module 6: Pub/Sub and Data Publishing. ~TBD min_

## Introduction

This lesson adds rules for the two new files to the existing file watcher, and points the file watcher at the tickerplant's channel.

## Key Concepts

We don't need a new file watcher for the published files. The `sampleOrder_fileWatcher` instance from Lesson 5.4 can watch for several file patterns, each calling a different analytic. All of these rules live in its `sampleOrder_fileWatcherConfig` config parameter.

### Adding the new file rules

Open `sampleOrder_fileWatcherConfig` (the override of DS_FILEWATCHER_MATCHTABLE created in Lesson 5.4). It already has one row for Module 5's batch loader, matching `sampleOrders_*.csv`. Add two more rows:

| fileregex | directory | analytic | alertTime |
|---|---|---|---|
| `sampleOrdersPub_*.csv` | same as the existing `sampleOrders_*.csv` row | `fileWatcher.pub_sampleOrders` | 00:00:00.000 |
| `sampleReferenceData_*.csv` | same as the existing `sampleOrders_*.csv` row | `fileWatcher.pub_sampleReferenceData` | 00:00:00.000 |

All three rules watch the same directory (the `fileStore` directory used in Lesson 5.6). The file watcher looks at every file that arrives, and it is the `fileregex` that decides which analytic runs. This is why the published orders file was given a different name in Lesson 6.5. `sampleOrdersPub_20260102.csv` doesn't match `sampleOrders_*.csv`, so only the new rule picks it up.

The two analytics named here are created in the next lesson.

### Pointing the file watcher at the tickerplant

For the file watcher's published data to reach the TP, it has to publish on the channel the TP subscribes to. In Lesson 4.3 the TP's `subscriptionChannel` was set to `refdata_channel`.

Open `sampleOrder_fileWatcher`, go to Instance Params and set:

| Parameter | Value for Course | Description |
|---|---|---|
| messagingServer | DS_MESSAGING_SERVER:DS | Messaging server config (see Lesson 6.1) |
| publishChannel | refdata_channel | Channel to publish on. Must match the TP's subscriptionChannel. |

Click Save. As noted in Lesson 6.2, instance parameter changes are not picked up by a running process, so restart the file watcher after saving.
