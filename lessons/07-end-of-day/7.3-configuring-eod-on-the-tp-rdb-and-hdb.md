# Lesson 7.3 - Configuring EOD on the TP, RDB and HDB

_Module 7: End-of-Day Processing and Persistence. ~10 min_

## Introduction

This lesson goes through the end-of-day parameters on each of the three core instances, and creates the list of course tables to save at EOD.

## Key Concepts

EOD is configured across all three instances from Lesson 4.3: the TP decides **when**, the RDB decides **what and how**, and the HDB decides **where**.

### Key Parameters for Course

**TP (`refdata_tp_reference_a`)**

| Parameter | Value for Course | Description |
|---|---|---|
| eodTime | 00:00 | Time EOD occurs at. Changed temporarily in Lesson 7.4 to trigger EOD sooner. |
| timeType | *(template default)* | Whether the TP timestamps updates and reads `eodTime` in `gmt` or `local` time |
| logDirectory | ENV=DELTADATA_HOME=/DeltaStreamData/tplog | Directory the TP logs to. A new log file is started at each EOD. |

**RDB (`refdata_rdb_reference_a`)**

| Parameter | Value for Course | Description |
|---|---|---|
| eodFunct | dxEODSaveAndDelete | End of day function (Lesson 7.2) |
| hdbProcess | refdata_hdb_reference_a | HDB to save to and reload at EOD |
| tableEodList | DS_TABLES_EOD_LIST:refdata_rdbEodConfig | Config listing the tables to save at EOD. Created below. |

**HDB (`refdata_hdb_reference_a`)**

| Parameter | Value for Course | Description |
|---|---|---|
| directory | ENV=DELTADATA_HOME=/DeltaStreamData/hdblog | HDB directory. The RDB writes its EOD partitions here (`.ds.rdb.hdbDir`) and the HDB loads from here. |
| reloadFunct | dxEmptyFunctionNull | Function called when the HDB is reloaded |

Both directories use the `ENV=` environment-variable form rather than a hard-coded path, as recommended in Lesson 3.5, so the same configuration works across environments.

### Creating the EOD table list

`DS_TABLES_EOD_LIST:DEFAULT` is empty (Lesson 7.2), so with the default setting the RDB would save nothing at EOD. We'll create our own version listing the course tables, using the same override technique as Lesson 5.4.

1. Search for `DS_TABLES_EOD_LIST` in the top left, right click on the DEFAULT version and select Override. Name the override `refdata_rdbEodConfig`.
2. Go to the Attribute Values tab and use **Add** to create two rows in the `tablesEod` column:

   | tablesEod |
   |---|
   | sampleOrders |
   | sampleReferenceData |

3. Click Save.
4. Open `refdata_rdb_reference_a`, go to Instance Params and set `tableEodList` to `DS_TABLES_EOD_LIST:refdata_rdbEodConfig`. Click Save.
5. Confirm the HDB's `directory` on `refdata_hdb_reference_a` matches the table above.
6. Restart the processes (for example via the `Refdata_launch_PROCS_A` workflow), since instance parameter changes are only picked up on startup (Lesson 6.2).
