# Lesson 7.2 - The Default EOD Function

_Module 7: End-of-Day Processing and Persistence. ~12 min_

## Introduction

This lesson shows how to find the RDB's end-of-day function and explains what the default function does.

## Key Concepts

### Checking for the EOD function

Open `refdata_rdb_reference_a` and go to Instance Params. The `eodFunct` parameter names the analytic that runs at EOD. By default it is **`dxEODSaveAndDelete`**.

> **Note:** screenshot to be captured: `refdata_rdb_reference_a` Instance Params with `eodFunct` highlighted.

`dxEODSaveAndDelete` is in the Analytics Library. Open it read-only. It is part of the KX DeltaStream package, so don't edit it (Lesson 3.2). If a process needs different EOD behaviour, create a new analytic in your own package and set `eodFunct` to it.

### Which tables get saved

The RDB only saves the tables listed in the config named by its `tableEodList` parameter. The default is `DS_TABLES_EOD_LIST:DEFAULT`, which has one column, `tablesEod`, and is empty:

The list is loaded into the RDB as the global variable `tablesEod`. Lesson 7.3 creates the course's own list.

### dxEODSaveAndDelete

```q
{[dt]
     .log.out[.z.h;"EOD function start ";(dt;.Q.w[]%1e6)];
     .ds.rte.disableGatewayQueries[.ds.cfg.procName];
     .ds.rte.disableGatewayQueries[.ds.cfg.hdbProcess];

     order:desc (tablesEod!count each value each tablesEod);
    {[d;t]
        .log.out[.z.h;("Performing EOD for ",(string t),", date ",(string d));d];
       if[count keys t;() xkey t];
       ![t;();0b;enlist `date];

       if[count[value t] and count complexColumns:where {(0=type x) and (type first x) in 0 99h} each flip value t;
            .[.al.callfunction[`dxEODSaveComplexTable];(d;t;complexColumns);{[t;d;x].pl.report_error_addInfo["Error writing complex table to HDB Dir";(x;.ds.rdb.hdbDir;d;`sym;t)]}[t;d]];
          ];
          if[not count[value t] and count complexColumns;
            @[{[t;d].Q.dpft[`:.;d;`sym;t]}[;d];t;{[t;d;x].pl.report_error_addInfo["Error writing table to HDB Dir";(x;.ds.rdb.hdbDir;d;`sym;t)]}[t;d]];
        ];

        // Clear the local namespace.
         .log.out[.z.h;"Resetting table: ",(string t);()];
        .[t;();:;.ds.schema[t]];
        if[.z.K>2.6; if[0=system"g"; .utils.gc[]]];
        .log.out[.z.h;("Finished EOD for ",(string t),", date ",(string d));(d;.Q.w[]%1e6)];
    }[dt;] each key order;
    // Connect to HDB and reload the dataBase.
    .ds.rte.enableGatewayQueries[.ds.cfg.procName];
    .ds.rte.enableGatewayQueries[.ds.cfg.hdbProcess];

    if[all `~/:.ds.rdb.hdbProcessListDetails@\:`dc_port;:()];
    .utils.hdb.reload1'[.ds.rdb.hdbProcessListDetails @\: `dc_hostport];

 }
```

The function takes `dt`, the date that has ended, and runs five steps:

1. **Disable gateway queries** on the RDB and HDB, so no queries are routed to them while data is being moved.
2. **Save and clear each table.** The tables come from the EOD config, loaded as the global `tablesEod`. Each is saved with `.Q.dpft` as a date partition with `sym` as the parted column (Lesson 7.1), then reset to its empty schema.
3. **Run garbage collection** to return the freed memory.
4. **Re-enable gateway queries.**
5. **Reload the HDB**, so the new partition can be queried.

### Functions used

| Function | Used for | Documentation |
|---|---|---|
| `.log.out` | Writing the progress lines to the process log | https://code.kx.com/platform/latest/api/logging.html#logout |
| `.Q.w` | Memory statistics shown in the log lines | https://code.kx.com/q/ref/dotq/#w-memory-stats |
| `.ds.rte.disableGatewayQueries` / `.ds.rte.enableGatewayQueries` | Stopping and resuming gateway queries to a process | Not in the public KX docs |
| `.ds.cfg.procName` / `.ds.cfg.hdbProcess` | This process's name, and its `hdbProcess` instance parameter | Not in the public KX docs |
| `xkey` | Unkeying a keyed table before saving | https://code.kx.com/q/ref/keys/ |
| `.al.callfunction` | Calling `dxEODSaveComplexTable` for tables with nested columns | https://code.kx.com/platform/latest/api/analytics.html#alcallfunction |
| `.Q.dpft` | Saving a table as a date partition with `sym` parted | https://code.kx.com/q/ref/dotq/#dpft-save-table |
| `.pl.report_error_addInfo` | Reporting a failed save to Control | https://code.kx.com/platform/latest/api/runtime.html#plreport_error_addinfo |
| `.ds.rdb.hdbDir` | The HDB directory, included in error reports | Not in the public KX docs |
| `.ds.schema` | The empty schema each table is reset to | Not in the public KX docs |
| `\g` (`system"g"`) | Checking the garbage collection mode | https://code.kx.com/q/basics/syscmds/#g-garbage-collection-mode |
| `.utils.gc` | Running garbage collection | https://code.kx.com/platform/latest/api/utils.html#utilsgc |
| `.ds.rdb.hdbProcessListDetails` | Host and port of each HDB paired with the RDB | Not in the public KX docs |
| `.utils.hdb.reload1` | Reloading an HDB | https://code.kx.com/platform/latest/api/utils.html#utilshdbreload1 |
