# Lesson 4.1 - What Is a Process Template?

_Module 4: Process Templates, Instances and Workflow Assembly · ~10 min_

## Introduction

This lesson defines a process template and surveys the core Delta Stream process templates available on KX Platform.

## Key Concepts

### Process template

A process template is a pre-defined bundle of q scripts and parameters that define a process, exposing a configurable parameter surface. A process instance in KX Platform must be based off a process template. KX provides a set of default process templates, covering core functionality that a KDB system may require. Some commonly used templates include a template for a tickerplant, real-time database and historical database, which are all core components of the KDB tick system.

The set of default process templates are often referred to as part of the Core Platform Templates. These templates are all locked q scripts, and are managed exclusively by KX and not visible to the user. A user may also create their own process template from scratch to suit their specific needs, although this course will not cover this.

### Core process templates

The table below lists the core Delta Stream process templates that KX provide:

| Template | Code | Description |
|---|---|---|
| Tickerplant | DS_TP | Delta Stream tickerplant template. |
| Real-Time Database | DS_RDB | Delta Stream real-time database template. |
| Historical Database | DS_HDB | Delta Stream historical-time database template. |
| Real-Time Engine | DS_RTE | Delta Stream real-time engine template, for subscribing and publishing data. |
| Gateway | DS_GW | Delta Stream gateway template, acts as an access point to a set of configurable databases. |
| Messaging Server | DS_DMSERVER | Delta Stream messaging server template which acts as a core for interprocess communication in KX Platform. Responsible for matching publishers and subscribers. |
| Filewatcher | DS_FILEWATCHER | Delta Stream filewatcher template. Monitors a directory for incoming files and triggers analytics to load, transform, and publish them. |
| Log Recovery | DS_LOG_RECOVERY | Delta Stream process template for replaying tickerplant logs and persisting. Replays tickerplant log files to recover or backfill data. Can replay and save at EOD or create an Intraday HDB. |
| Report Generator | DS_REPORT_GENERATOR | Delta Stream report generator template. Automated framework for generating reports. Useful for user exposed functions/jobs as allows scheduling and manual runs. |

This module will work with 3 process templates **Tickerplant, RDB and HDB** to build the course's tick-plant skeleton. The remaining templates are listed here for orientation: Filewatcher is covered in Module 5, Messaging Server in Module 6, Gateway in Module 8.
