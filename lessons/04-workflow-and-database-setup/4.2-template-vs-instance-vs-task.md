# Lesson 4.2 - Template vs. Instance vs. Task

_Module 4: Process Templates, Instances and Workflow Assembly · ~5 min_

## Introduction

This lesson distinguishes three terms used throughout Delta Control: process template, process instance, and process task.

## Key Concepts

### Template vs. Instance vs. Task

The below table defines the core components involved in running a process in KX Platform.

| Term | Official Definition | Source |
|---|---|---|
| **Process template** | "KX Control installs with a number of default process templates, each with a description and an example configuration" | process_templates.html |
| **Process instance** | "A process instance is derived from a process template" and "can be configured by modifying a set of parameters" | process_instances.html |
| **Process task** | "An automated execution mechanism derived from a process instance" — used "where a process instance is to be launched or run on an automated schedule" | process_tasks.html |

The template tier was covered in Lesson 4.1 (RDB, TP, HDB templates). This lesson introduces the other two, and the relationship between all three: **one template can produce many instances**, and **each instance can have tasks** tied to it for scheduled or automated operation.
